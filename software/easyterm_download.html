EasyTerm

A configurable serial-terminal project by Perry Newlin.

Project features

The project’s original preview describes a Windows serial terminal with custom baud rates, even/odd/none parity, interface scaling, and selectable application themes.

Release availability

A downloadable release is currently unavailable. The earlier ZIP download link returned a missing-file response when checked during this site update.

For browser-based serial timing calculations, use the UART baud rate calculator.
