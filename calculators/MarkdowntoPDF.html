Writing and exporting

Use # for headings, **bold** for emphasis, and triple backticks for code. Tables use vertical bars between columns. Put inline LaTeX between $…$ or \(…\), and display equations between $$…$$ or \[…\]. Write currency dollar signs as \$.

Choose Print / Save PDF, then select your browser’s PDF destination. Page size, margins, and browser headers are controlled in that dialog. The PDF uses black text on white, with selectable text and automatic page breaks. Very wide tables and long equations may need landscape orientation.

The editor processes text in this browser. Linked images load from their original hosts. Download Markdown to keep a copy of your work before leaving the page. The document limit is 100,000 characters.

Rendering

GitHub-flavored Markdown is rendered with Marked and sanitized with DOMPurify. Raw HTML is displayed as text. KaTeX renders the supported LaTeX math commands with external-resource commands disabled. An unsupported equation stays visible as source text.
