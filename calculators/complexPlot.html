Reading the complex plane

The number z = a + jb is the point (a, b) and the vector from the origin to that point. The horizontal axis represents the real part; the vertical axis represents the imaginary part. Both axes use the same scale, so a 45° vector appears at 45°.

The magnitude is |z| = √(a² + b²), calculated with a scaled hypot operation to avoid unnecessary overflow. Phase is atan2(b, a), measured counterclockwise from the positive real axis in degrees. The zero vector has no defined direction.

Input components must be finite and have magnitude at most 10150. Results are rounded to eight significant digits for display. CSV exports contain the underlying floating-point values. For operations on these values, use the phasor calculator.

Worked example

The vector −3 + j4 ends at (−3, 4), in the second quadrant. Its magnitude is √(9 + 16) = 5. The phase is atan2(4, −3), approximately 126.869898°. Using arctan(4/−3) alone would lose the quadrant information.
